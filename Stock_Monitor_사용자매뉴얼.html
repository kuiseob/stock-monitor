🚀 빠른 시작

Windows 사용자

1 run.bat 더블클릭

프로젝트 폴더에서 run.bat 파일을 더블클릭하면 자동으로 실행됩니다.

2 앱 로딩

가상환경 생성, 패키지 설치, 앱 실행이 자동으로 진행됩니다. (1-2분 소요)

3 브라우저 접속

브라우저에서 http://localhost:8501로 접속합니다.

✅ 완료! 이제 실시간 주식 모니터링을 시작할 수 있습니다.

macOS/Linux 사용자

cd stock-monitor
source venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit/app.py

🔧 설치 방법

시스템 요구사항

항목 요구사항
운영체제 Windows 7+, macOS, Linux
Python 3.9 이상
메모리 2GB 이상
디스크 500MB 이상
인터넷 필수

Step 1: Python 설치

  1. https://www.python.org/downloads/ 에서 Python 다운로드
  2. 인스톨러 실행
  3. 중요: "Add Python to PATH" 체크
  4. "Install Now" 클릭

Step 2: 프로젝트 다운로드

git clone 
cd stock-monitor

Step 3: 가상환경 설정

Windows:

python -m venv venv
venv\Scripts\activate.bat

macOS/Linux:

python3 -m venv venv
source venv/bin/activate

Step 4: 의존성 설치

pip install -r requirements.txt

Step 5: 환경변수 설정

  1. .env.example을 .env로 복사
  2. 텍스트 에디터로 .env 파일 열기
  3. 다음 값들을 입력: 
    SAMSUNG_API_KEY=your_api_key
SAMSUNG_ACCOUNT_ID=your_account_id
SAMSUNG_API_SECRET=your_secret

▶️ 앱 실행

방법 1: run.bat (Windows - 권장)

double-click run.bat

방법 2: 명령줄

streamlit run streamlit/app.py

방법 3: 독립 실행형 EXE (Windows)

  1. build.bat 실행
  2. dist/StockMonitor.exe 생성 대기 (2-5분)
  3. dist/StockMonitor.exe 더블클릭
💡 팁: 브라우저가 자동으로 열리지 않으면 http://localhost:8501을 직접 입력하세요.

📖 사용 방법

대시보드 구조

앱은 4개의 탭으로 구성되어 있습니다:

1️⃣ Overview (실시간 모니터링)

  • 5개 종목의 실시간 가격 표시
  • 외국인/기관 순매수량 추적
  • 거래량 표시
  • 1초 단위 자동 갱신

2️⃣ Analytics (차트 분석)

  • 24시간 가격 차트
  • 거래량 분석
  • 최고/최저/평균가
  • 통계 요약

3️⃣ History (과거 데이터)

  • 날짜 범위 선택
  • 과거 데이터 조회
  • CSV 다운로드

4️⃣ Settings (환경설정)

  • 데이터 보관 기간 설정
  • 오래된 데이터 정리
  • 캐시 초기화

시작 단계

1 종목 선택

좌측 사이드바에서 모니터링할 종목을 선택합니다 (최대 5개).

2 데이터 수집 시작

"▶️ 시작" 버튼을 클릭하면 실시간 데이터 수집이 시작됩니다.

3 실시간 모니터링

Overview 탭에서 실시간 가격과 거래 현황을 확인합니다.

4 분석 및 조회

Analytics, History 탭에서 차트와 통계를 확인합니다.

⭐ 주요 기능

실시간 데이터 수집

  • 주식 가격 (현재가, 입찰가, 매도가)
  • 거래량
  • 외국인 매수/매도량
  • 기관 매수/매도량

데이터 분석

  • 이동평균 계산
  • 변동성 분석
  • 추세 분석
  • 일일 통계

자동 재연결

  • 지수 백오프 재시도 (1초 → 2초 → 4초 → ...)
  • 최대 5회 재시도
  • 자동 재연결 후 계속 수집

데이터 저장

  • SQLite 데이터베이스에 저장
  • 자동 데이터 정리 (30일 유지)
  • CSV 다운로드 가능

🐛 문제 해결

Python을 찾을 수 없다는 오류

⚠️ 문제: "python" is not recognized

해결책:

  1. Python을 재설치
  2. 설치 시 "Add Python to PATH" 반드시 체크
  3. 컴퓨터 재부팅
  4. 터미널 새로 열기

포트 8501이 이미 사용 중

⚠️ 문제: Address already in use

해결책:

streamlit run streamlit/app.py --server.port 8502

API 연결 실패

⚠️ 문제: Connection refused / Timeout

확인사항:

  • 인터넷 연결 확인
  • .env 파일의 API 키가 올바른지 확인
  • 방화벽 설정 확인
  • logs/app.log 확인

📞 기술 지원

자주 묻는 질문

Q: 실시간 데이터가 안 보여요

A: 다음을 확인하세요:

  • API 키가 올바르게 설정되었는가?
  • "▶️ 시작" 버튼을 클릭했는가?
  • 인터넷 연결이 정상인가?

Q: 앱이 느려요

A: 다음을 시도하세요:

  • 모니터링 종목을 줄여보세요
  • Settings에서 캐시를 초기화하세요
  • 오래된 데이터를 정리하세요
